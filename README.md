## Практическое задание №4


### C4 — Уровень 1. Контекст

Что у нас в центре — система Система управления ЭМК. Вокруг — кто с ней работает и какие внешние сервисы дёргаем.

![Уровень 1](1.png)

Что сюда заходит и зачем:

- **Студенты** ищут курсы, записываются, проходят уроки, отмечают прогресс
- **Преподаватели** создают курсы, прикрепляют материалы, смотрят, кто отстаёт
- **Админы** управляют хостингами и смотрят сводную статистику
- **Поддержка** разбирает обращения, может отменить запись, помочь со входом
- **ЮKassa** — для платных курсов
- **SMTP** — отправляем письма (приглашения, напоминания)
- **Видеохостинг** — храним и стримим видео-уроки
- **Coursera / Stepik** — импортируем оттуда курсы
- **Push** — пушим уведомления о новых уроках, о завершении курса

### C4 — Уровень 2. Контейнеры

![Уровень 2](2.png)

Что внутри:

- **Веб-приложения студента / преподавателя / админа** — три отдельных SPA на React
- **nginx** — раздаёт статику, проксирует API, держит SSL
- **Бэкенд** — один на всё, разделён внутри на модули (контент, обучение, пользователи, аналитика). Микросервисы пока не нужны
- **PostgreSQL** — основная база (пользователи, преподаватели, курсы, модули, уроки, хостинги, треки прохождения)
- **Redis** — кэш каталога курсов, сессии, очередь задач
- **S3** — файлы (PDF, изображения)

---

### Стек

#### Фронт
- **React + TypeScript** — три SPA с разными ролями. Разработчиков в РФ много.
- **Vite** — быстрая сборка.
- **Tailwind** — быстро верстать, единый стиль на 3 интерфейса.

#### Бэк
- **Python + FastAPI** — быстро поднимается. На рынке много Python-разработчиков.
- **SQLAlchemy + Alembic** — стандартная связка для работы с PostgreSQL.
- **Pydantic** — валидация входящих данных по контракту.
- **Celery + Redis** — фоновые задачи (рассылки, пересчёт аналитики).

#### Хранилища
- **PostgreSQL** — реляционка
- **Redis** — кэш и сессии.
- **S3 (MinIO или Yandex Object Storage)** — медиа-файлы.

#### Инфра
- **Docker + Docker Compose** — одинаковая среда у всех разработчиков и на проде.
- **nginx** — gateway, SSL, статика.
- **GitLab CI/CD** — пайплайны.
- **Prometheus + Grafana** — метрики.
- **Sentry** — ошибки фронта и бэка.
