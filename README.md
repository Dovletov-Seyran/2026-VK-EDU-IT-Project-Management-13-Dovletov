### MVP и MLP

#### MVP

Минимум, чтобы преподаватель мог опубликовать курс, а студент — пройти его.

- Поиск курсов в каталоге
- Запись на курс
- Последовательное прохождение уроков
- Видеть прогресс по курсу
- Отметка урока пройденным
- Создание курса
- Иерархия курс/модуль/урок
- Прикрепление медиа к уроку
- Управление платформами (хостинг)
- Связь с поддержкой

#### MLP

- Просмотр медиа прямо в системе (встроенный плеер)
- Дашборд прогресса студентов для преподавателя
- Редактирование опубликованного курса
- Сводная аналитика для администратора
- Полноценная поддержка с тикетами

### #2 — Запись студента на курс

#### ФТ

- Кнопка «Записаться» отображается на детальной странице курса только авторизованному студенту
- При нажатии система проверяет, не записан ли студент на этот курс ранее (по бизнес-ограничению из отчёта: повторное зачисление запрещено)
- Если уже записан — кнопка заменяется на «Перейти к курсу» и нажатие ведёт на первый незавершённый урок
- При успешной записи система создаёт запись в сущности «Трек прохождения» со статусом «начат» для первого урока
- После записи отображается тостер «Вы записаны на курс» и происходит переход в «Мои курсы»
- При неудачной записи (ошибка сети, курс в статусе «Завершён») система показывает алерт с описанием причины
- Преподаватель курса автоматически получает уведомление о новом студенте

#### НФТ

- Время отклика сервера на POST `/v1/enrollments` не превышает 500 мс на 95-м перцентиле
- Кнопка «Записаться» защищена от двойного нажатия (debounce + блокировка после первого клика до ответа сервера)
- Запись на курс должна быть транзакционной: либо создаётся и зачисление, и стартовый прогресс, либо ничего
- Система выдерживает пиковую нагрузку 500 одновременных записей в минуту (старт нового семестра)

### #5 — Отметка урока пройденным

#### ФТ — Функциональные требования

- На странице урока есть кнопка «Отметить как пройденный», доступная только записанному на курс студенту
- При нажатии система меняет статус записи прогресса с «начат» на «завершён» и фиксирует дату завершения
- Согласно бизнес-ограничению из отчёта, обратный переход «завершён → начат» запрещён, кнопка отмены не отображается
- После отметки автоматически разблокируется следующий урок в модуле, а текущий помечается зелёной галочкой в боковом меню
- Прогресс по курсу пересчитывается и обновляется в реальном времени без перезагрузки страницы
- Если урок последний в курсе — отображается экран поздравления и предлагается оценить курс
- Преподаватель в своём дашборде видит обновлённый прогресс студента

#### НФТ — Нефункциональные требования

- Изменение статуса прогресса записывается в БД не дольше 200 мс
- UI обновляется оптимистично: галочка появляется сразу, без ожидания ответа сервера; в случае ошибки откатывается с тостером
- Действие идемпотентно: повторное нажатие на уже пройденный урок не создаёт дублей в БД
- История изменений прогресса логируется для последующей аналитики (event-sourcing)
